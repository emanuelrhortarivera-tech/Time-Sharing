💡 ¿Qué está ocurriendo?

El CPU del servidor distribuye pequeños intervalos de tiempo (denominados Time Quanta) entre los procesos de diferentes usuarios. El cambio rápido de un usuario a otro genera la ilusión óptica y operativa de que todos están utilizando el servidor exactamente al mismo tiempo.

🔍 Conceptos Clave

• Time-Sharing (Tiempo Compartido): Técnica donde el procesador reparte su tiempo de cálculo entre múltiples usuarios de forma secuencial.
• Algoritmo Round-Robin: Cada usuario recibe un turno equitativo en un ciclo continuo.
• Context Switch (Cambio de Contexto): Transición ultra-rápida que realiza el procesador para suspender un proceso y atender el siguiente.
